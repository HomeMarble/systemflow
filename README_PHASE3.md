# هوم ماربل ERP — المرحلة الثالثة

ملفات جديدة فقط، ولم يتغيّر أي ملف قديم إلا سطر واحد في `index.html` لتحميل `js/phase3.js`.

## التشغيل
1. من SQL Editor شغّل `database/0003_homemarble_phase3.sql` بعد الملفات 0001 و0002. الملف إضافي فقط، وتشغيله أكثر من مرة آمن.
2. ارفع مجلد `homemarble/` كما هو.
3. حسابات الأدوار الجديدة تُنشأ تلقائياً (راجع HomeMarble_Accounts_v2.pdf).

## الميزات
- **تحديد الكل والحذف الجماعي** في كل جداول النظام (العملاء، الطلبات، المستندات، المخزون، المشتريات، الزيارات، التركيبات، الدعم، الدردشات، التقارير، سلة المحذوفات، وكل جداول المرحلة الثالثة). تقدر تحدد عنصر واحد أو الكل ثم تضغط «حذف المحدد»، وكل المحذوفات تُحفظ في سلة المحذوفات.
- **المحاسبة والمالية**: الإيرادات وسندات الصرف، ربط المدفوعات بالفواتير، تقارير حسب الفترة أو الفرع، وطباعة.
- **شؤون الموظفين**: ملفات الموظفين، الإجازات واعتمادها، السياسات الداخلية، وبوابة لكل موظف.
- **الإشعارات والتواصل الداخلي**: إعلانات لكل الموظفين أو لوظيفة محددة، مع تنبيه في الجرس.
- **واتساب**: رسائل جاهزة في صفحات الطلب والمستند والعميل.
- **التسويق**: حملات لشرائح العملاء عبر واتساب أو البريد، مع إرفاق كوبون وحفظ سجل الحملات.
- **المتجر الإلكتروني** (`#/shop`): للزوار، مرتبط بالمخزون، والطلبات تتحول لعميل وطلب بضغطة.
- **الكوبونات** (للمدير والمدير التنفيذي فقط): توليد عشوائي أو كتابة يدوية، الخصم بنسبة أو مبلغ، على كل المنتجات أو منتج محدد أو نوع منتج، فترة الصلاحية، حد للاستخدام، ورقم واتساب أو بريد للتحويل التلقائي. رابط الكوبون `#/coupon/CODE` يحوّل الزائر تلقائياً للواتساب أو البريد، أو يعرض الأزرار. الخصم يُحسب ويُتحقق منه في قاعدة البيانات.
- **دليل الاستخدام والتسليم** داخل النظام.
